# Vampire Crawlers Guide Data

Unofficial, hand-checked data tables for **Vampire Crawlers: The Turbo Wildcard from Vampire Survivors**.

The same tables are published at **https://vampirecrawler.com/press/** under CC BY-SA 4.0.

Also mirrored on Kaggle: [Vampire Crawlers Guide Data (Unofficial)](https://www.kaggle.com/datasets/thedoga/vampire-crawlers-guide-data).

## Files

| File | Rows | Columns (first four) |
|---|---:|---|
| `achievements.csv` | 161 | #, Achievement, Official Steam description, Unlock |
| `arcana.csv` | 16 | Icon, Arcana, Effect, Unlock condition |
| `boss-notes.csv` | 25 | Enemy, HP, Armor, Knockback |
| `bosses.csv` | 77 | Enemy, HP, Armor, Knockback |
| `card-damage.csv` | 17 | Icon, Card, Mana, Slots |
| `cards.csv` | 21 | Icon, Card, Mana, Slots |
| `enemies.csv` | 65 | Icon, Enemy, HP, XP |
| `enemy-resistances.csv` | 45 | Enemy, HP, Knockback, Disarm |
| `evolutions.csv` | 18 | Evolution, Weapon, + Item, Mana |
| `gems.csv` | 62 | Icon, Gem, Rarity, Effect |
| `power-ups.csv` | 19 | Icon, Power Up, Max rank, Per rank |
| `relics.csv` | 19 | Icon, Relic, Official effect, Where to find it |
| `unlocks.csv` | 182 | #, Icon, Unlock, How you get it |
